MIX_LoadRawAudio

メモリバッファから無圧縮PCMデータを読み込む

ヘッダ

SDL3_mixer/SDL_mixer.h

構文

MIX_Audio * MIX_LoadRawAudio(MIX_Mixer *mixer, const void *data, size_t datalen, const SDL_AudioSpec *spec);

引数

MIX_Mixer *mixerオーディオデータを使用するミキサー. NULLも可
const void *dataオーディオデータが書き込まれたバッファ
size_tdatalenバッファのバイト数
const SDL_AudioSpec *specdataに書き込まれた無圧縮データの形式

戻り値

(MIX_Audio *) ミキサーで音声を発生させるために使用できるオーディオオブジェクトを戻す. 失敗のときNULLを戻す. SDL_GetError()を呼んで詳細を知ることができる.

詳細

これは無圧縮PCMのストリーミングの別の選択肢である: SDL_AudioStreamはSDL_IOStreamと同様にトラックに結びつけることができ, ミックスのとき必要に応じてこれらのデータ源から読み込まれる. この関数は複数回再生する目的で静的なオーディオデータを読み込む場合に便利である.

この関数は無圧縮データを全て読み込み, RAMにコピーして保持する. 元のデータがMIX_Audioよりも長期間有効な場合は, MIX_LoadRawAudioNoCopy()を使用して余分な領域の確保とコピーを避けることができおる.

MIX_Audioオブジェクトは複数のミキサーで共有できる. mixer引数はこのオーディオを最も使うミキサーを示唆するもので, 最適化が適用される場合があるが, 必須ではなくミキサーとしてNULLを指定することもできる.

スレッドセーフ

この関数はどのスレッドからも安全に呼べる.
