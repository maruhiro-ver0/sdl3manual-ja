TTF_OpenFont

ポイントサイズを指定してフォントをファイルから生成する

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

TTF_Font * TTF_OpenFont(const char *file, float ptsize);

引数

const char *fileフォントファイルのパス名
floatptsize新たに開くフォントのポイントサイズ

戻り値

(TTF_Font *) 利用可能なTTF_Font, エラーのときNULLを戻す. SDL_GetError()を呼んで詳細を知ることができる.

詳細

一部の.fonフォントはファイル内に複数のフォントが埋め込まれている. その場合, ポイントサイズはサイズを選択するインデックス番号になる. 値が大きすぎる場合, 最も大きなインデックス番号のサイズになる.

TTF_Fontを使い終えたらTTF_CloseFont()で破棄すること.

スレッドセーフ

この関数はどのスレッドからも安全に呼べる.

バージョン

SDL_ttf 3.0.0
