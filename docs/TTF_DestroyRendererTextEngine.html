TTF_DestroyRendererTextEngine

SDLレンダラへのテキスト描画のためのテキストエンジンを破棄する

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

void TTF_DestroyRendererTextEngine(TTF_TextEngine *engine);

引数

TTF_TextEngine *engineTTF_CreateRendererTextEngine()で生成されたTTF_TextEngineオブジェクト

詳細

このテキストエンジンで生成された全てのテキストはこの関数を呼ぶ前に破棄する必要がある.

スレッドセーフ

この関数はテキストエンジンを生成したスレッドから呼ぶ必要がある.

バージョン

SDL_ttf 3.0.0
