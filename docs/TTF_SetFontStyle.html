TTF_SetFontStyle

フォントのスタイルを設定する

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

void TTF_SetFontStyle(TTF_Font *font, TTF_FontStyleFlags style);

引数

TTF_Font *font設定するフォント
TTF_FontStyleFlagsstyleフォントスタイルのビット論理和

戻り値

(TTF_FontStyleFlags) 現在のフォントのスタイルをビットの論理和で戻す.

詳細

このフォントを使用するTTF_Textオブジェクトは更新され, キャッシュに既に生成されたグリフが存在すれば消去される.

フォントのスタイルは次のビットフラグの論理和である:

  • TTF_STYLE_NORMAL (0)
  • TTF_STYLE_BOLD
  • TTF_STYLE_ITALIC
  • TTF_STYLE_UNDERLINE
  • TTF_STYLE_STRIKETHROUGH

スレッドセーフ

この関数はフォントを生成したスレッドから呼ぶ必要がある.

バージョン

SDL_ttf 3.0.0
