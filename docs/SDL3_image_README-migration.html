SDL_image 3.0への移行

このガイドではアプリケーションをSDL_image 2.0からSDL_image 3.0に移行するための有益な情報を提供する.

IMG_Init()とIMG_Quit()は必要なくなった. 動的にライブラリを読み込む必要がある画像形式の場合, それは自動的に行われる.

IMG_GetError()はSDL_GetError()に置き換えられた.

SDL_RWopsの引数を取る*_RW()が付けられた関数の名前は, SDL_IOStreamの引数を取るため*_IO()となった.

IMG_Linked_Version()はIMG_Version()に置き換えられた.
