IMG_CreateAnimationDecoder_IO

連続した画像ファイルをSDL_IOStreamから読み込むデコーダを生成する

ヘッダ

SDL3_image/SDL_image.h

構文

IMG_AnimationDecoder * IMG_CreateAnimationDecoder_IO(SDL_IOStream *src, bool closeio, const char *type);

引数

SDL_IOStream *src連続した画像を含むSDL_IOStream
boolcloseio真のとき戻る前にSDL_IOStreamを自動的に閉じる. 偽のとき開いたままにする
const char *typeデータを表す拡張子("WEBP"等)

戻り値

(IMG_AnimationDecoder *) 新しいIMG_AnimationDecoder, 失敗のときNULLを戻す. SDL_GetError()を呼んで詳細を知ることができる.

詳細

現在はこれらの形式のアニメーションに対応している:

  • ANI
  • APNG
  • AVIFS
  • GIF
  • WEBP

closeioが真の場合, 関数が成功してもしなくても戻る前にsrcは閉じる.

バージョン

SDL_image 3.4.0以降
