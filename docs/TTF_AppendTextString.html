TTF_AppendTextString

テキストオブジェクトにUTF-8テキストを追加する

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

bool TTF_AppendTextString(TTF_Text *text, const char *string, size_t length);

引数

TTF_Text *text変更するテキスト
const char *string追加するUTF-8テキスト
size_tlengthテキストのバイト数. 0のときNUL終端のテキスト

戻り値

(bool) 成功のとき真, 失敗のとき偽を戻す. SDL_GetError()を呼んで詳細を知ることができる.

詳細

この関数は内部のテキストの再構築を引き起こす場合がある.

スレッドセーフ

この関数はテキストを生成したスレッドから呼ぶ必要がある.

バージョン

SDL_ttf 3.0.0
