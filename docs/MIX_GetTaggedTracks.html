MIX_GetTaggedTracks

指定したタグのトラックを全て得る

ヘッダ

SDL3_mixer/SDL_mixer.h

構文

MIX_Track ** MIX_GetTaggedTracks(MIX_Mixer *mixer, const char *tag, int *count);

引数

MIX_Mixer *mixer問い合わせるミキサー
const char *tag検索するタグ
int *count戻されたトラックの数の代入先へのポインタ. NULLも可

戻り値

(MIX_Track **) NULL終端のトラックの配列を戻す. 失敗のときNULLを戻す. SDL_GetError()を呼んで詳細を知ることができる. 戻されたポインタは不要になったときSDL_free()で解放する必要がある.

詳細

トラックの順序には保証がない.

スレッドセーフ

この関数はどのスレッドからも安全に呼べる.

バージョン

SDL_image 3.0.0以降
