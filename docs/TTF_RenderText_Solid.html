TTF_RenderText_Solid

UTF-8テキストを速度重視の画質で新しい8ビットサーフェイスにレンダリングする

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

SDL_Surface * TTF_RenderText_Solid(TTF_Font *font, const char *text, size_t length, SDL_Color fg);

引数

TTF_Font *fontレンダリングするフォント
const char *textレンダリングするUTF-8テキスト
size_tlengthテキストのバイト長. 0のときNUL終端のテキスト
SDL_Colorfgテキストの前景色

戻り値

(SDL_Surface *) 8ビットパレットサーフェイスを戻す. エラーのときNULLを戻す.

詳細

この関数は新たに8ビットパレットサーフェイスを生成する. サーフェイスの0ピクセルはキーカラーで, 透明な背景色となる. 1ピクセルは設定されたテキストの色である.

この関数は改行しないため, どれだけ文字列が長くてもサーフェイスのテキストは1行である. 改行して複数行にする必要がある場合は, 代わりにTTF_RenderText_Solid_Wrapped()を使用すること.

この関数は改行コードで改行しない.

他の画質レベルでのレンダリングはTTF_RenderText_Shaded, TTF_RenderText_Blended, TTF_RenderText_LCDで行える.

スレッドセーフ

この関数はフォントを生成したスレッドから呼ぶ必要がある.

バージョン

SDL_ttf 3.0.0
