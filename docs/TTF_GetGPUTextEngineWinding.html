TTF_GetGPUTextEngineWinding

GPUテキストエンジンのTTF_GetGPUTextDrawDataが戻した頂点の巻き順を得る

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

TTF_GPUTextEngineWinding TTF_GetGPUTextEngineWinding(const TTF_TextEngine *engine);

引数

const TTF_TextEngine *engineTTF_CreateGPUTextEngine()で生成したTTF_TextEngineオブジェクト

戻り値

(TTF_GPUTextEngineWinding) GPUテキストエンジンが使用する巻き順を戻す. エラーのときTTF_GPU_TEXTENGINE_WINDING_INVALIDを戻す.

スレッドセーフ

この関数はテキストエンジンを生成したスレッドから呼ぶ必要がある.

バージョン

SDL_ttf 3.0.0
