TTF_GetTextColorFloat

テキストオブジェクトの色を得る

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

bool TTF_GetTextColorFloat(TTF_Text *text, float *r, float *g, float *b, float *a);

引数

TTF_Text *text問い合わせるTTF_Text
float *r0～1の赤要素の代入先へのポインタ. NULLも可
float *g0～1の緑要素の代入先へのポインタ. NULLも可
float *b0～1の青要素の代入先へのポインタ. NULLも可
float *a0～1のα要素の代入先へのポインタ. NULLも可

戻り値

(bool) 成功のとき真, 失敗のとき偽を戻す. SDL_GetError()を呼んで詳細を知ることができる.

スレッドセーフ

この関数はテキストを生成したスレッドから呼ぶ必要がある.

バージョン

SDL_ttf 3.0.0
