IMG_CreateAnimationEncoder

連続した画像ファイルを保存するエンコーダを生成する

ヘッダ

SDL3_image/SDL_image.h

構文

IMG_AnimationEncoder * IMG_CreateAnimationEncoder(const char *file);

引数

const char *fileアニメーションを保存するファイルのパス名

戻り値

(IMG_AnimationEncoder *) 新しいIMG_AnimationEncoder, 失敗のときNULLを戻す. SDL_GetError()を呼んで詳細を知ることができる.

詳細

現在はこれらの形式のアニメーションに対応している:

  • ANI
  • APNG
  • AVIFS
  • GIF
  • WEBP

ファイル形式はファイルの拡張子で決まる. 例えば, "file.webp"はWEBPでエンコードされる.

バージョン

SDL_image 3.4.0以降
