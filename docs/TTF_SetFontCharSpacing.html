TTF_SetFontCharSpacing

レンダリングされた2つの文字の間に挿入される空白をピクセル単位で設定する

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

bool TTF_SetFontCharSpacing(TTF_Font *font, int spacing);

引数

int
const TTF_Font *font設定するフォント
spacingフォントのピクセル単位の文字間スペース

戻り値

(bool) 成功のとき真, 失敗のとき偽を戻す. SDL_GetError()を呼んで詳細を知ることができる.

詳細

spacingの値は, 通常のグリフの送り幅(advence)に加え, それぞれの文字の後に均一に追加される.

スペースは負の値もありうる. この場合は文字間が狭まる.

このフォントを使用するTTF_Textオブジェクトは更新される.

スレッドセーフ

この関数はフォントを生成したスレッドから呼ぶ必要がある.

バージョン

SDL_ttf 3.4.0
