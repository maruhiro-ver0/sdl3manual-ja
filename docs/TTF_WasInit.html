TTF_WasInit

SDL_ttfが初期化されているかチェックする

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

int TTF_WasInit(void);

戻り値

(int) 現在の初期化回数を戻す. 最終的にはこの回数だけTTF_Quit()を呼ぶ必要がある.

詳細

この関数は, TTF_Quit()で終了処理を要求された回数を除くTTF_Init()でライブラリが初期化された回数を戻す.

この値が0より大きいならばライブラリは初期化され使用することができる. 0ならば初期化されていない.

戻り値の型は符号あり整数だが, この関数が負の数を戻すことはない.

スレッドセーフ

この関数はどのスレッドからも安全に呼べる.

バージョン

SDL_ttf 3.0.0
