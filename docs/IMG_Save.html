IMG_Save

SDL_Surfaceを画像ファイルとして保存する

ヘッダ

SDL3_image/SDL_image.h

構文

bool IMG_Save(SDL_Surface *surface, const char *file);

引数

SDL_Surface *surface保存するSDL_Surface
const char *file新たに生成するファイルのパス名

戻り値

(bool) 成功のとき真, エラーのとき偽を戻す. SDL_GetError()を呼んで詳細を知ることができる.

詳細

ファイルが既に存在する場合は上書きされる.

品質のある形式の場合, デフォルトとして90が使用される.

バージョン

SDL_image 3.4.0以降
