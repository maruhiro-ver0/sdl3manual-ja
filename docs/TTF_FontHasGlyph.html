TTF_FontHasGlyph

指定したUNICODEコードポイントのグリフがフォントに存在するかチェックする

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

bool TTF_FontHasGlyph(TTF_Font *font, Uint32 ch);

引数

TTF_Font *fontチェックするフォント
Uint32chチェックするコードポイント

戻り値

(bool) 指定した文字のグリフがフォントにあれば真, なければ偽を戻す.

スレッドセーフ

この関数はフォントを生成したスレッドから呼ぶ必要がある.

バージョン

SDL_ttf 3.0.0
