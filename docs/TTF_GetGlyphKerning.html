TTF_GetGlyphKerning

2つのUNICODEコードポイントのグリフの間のカーニングサイズを得る

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

bool TTF_GetGlyphKerning(TTF_Font *font, Uint32 previous_ch, Uint32 ch, int *kerning);

引数

TTF_Font *font問い合わせるフォント
Uint32previous_ch前のコードポイント
Uint32ch現在位置のコードポイント
int *kerning2つのグリフの間のピクセル単位のカーニングサイズの代入先へのポインタ. NULLも可

戻り値

(bool) 成功のとき真, 失敗のとき偽を戻す. SDL_GetError()を呼んで詳細を知ることができる.

スレッドセーフ

この関数はフォントを生成したスレッドから呼ぶ必要がある.

バージョン

SDL_ttf 3.0.0
