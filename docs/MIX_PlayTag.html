MIX_PlayTag

特定のタグの全てのトラックの再生を開始(または再開)する

ヘッダ

SDL3_mixer/SDL_mixer.h

構文

bool MIX_PlayTag(MIX_Mixer *mixer, const char *tag, SDL_PropertiesID options);

引数

MIX_Mixer *mixerタグ付けされたトラックのミキシングを開始(または再開)するミキサー
const char *tagトラックの検索で使用するタグ
SDL_PropertiesIDoptions再生のプロパティ. 0も可

戻り値

(bool) 成功のとき真, エラーのとき偽を戻す. SDL_GetError()を呼んで詳細を知ることができる.

詳細

この関数はMIX_PlayTrack()と同様の規則に従う. 詳しくはそのドキュメントを参照すること. 違いはMIX_PlayTag()はMIX_TagTrack()で特定のタグが付けられた複数のトラックを一度に扱える点である.

タグ付けされたトラックが異なるサンプルリングレートの場合, optionsは*_FRAMES_NUMBERプロパティではなく*_MILLISECONDS_NUMBERプロパティを使用し, SDL_mixerはそれぞれのトラックに適用しようとする.

この関数はタグ付けされた全てのトラックを再生(または再開)したとき真を戻す. 失敗したトラックがある場合, この関数は偽を戻すが, その場合でも再生可能なトラックは全て再生を開始する.

ミキシング処理の視点では, 成功した全てのトラックは完全に同時に再生(再開)を開始する.

スレッドセーフ

この関数はどのスレッドからも安全に呼べる.

バージョン

SDL_image 3.0.0以降
