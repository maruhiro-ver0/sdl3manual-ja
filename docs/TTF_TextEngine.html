TTF_TextEngine

テキストオブジェクトの生成で使用するテキストエンジンの型

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

typedef struct TTF_TextEngine TTF_TextEngine;

詳細

これはアプリケーションとライブラリがテキストオブジェクトのレンダリングでカスタマイズを適用するために使用するパブリックなインターフェースである. 詳細は<SDL3_ttf/SDL_textengine.h>を参照すること.

ライブラリは4種類のテキストエンジンを提供する:

  • SDL_Surfaceへの描画. TTF_CreateSurfaceTextEngine()で生成する
  • SDL 2Dレンダラで描画する. TTF_CreateRendererTextEngine()で生成する
  • SDL GPU APIで描画する. TTF_CreateGPUTextEngine()で生成する
  • OpenGLで描画する. TTF_CreateGLTextEngine()で生成する

バージョン

SDL_ttf 3.0.0
