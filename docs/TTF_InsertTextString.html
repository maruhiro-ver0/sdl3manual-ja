TTF_InsertTextString

テキストオブジェクトにUTF-8テキストを挿入する

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

bool TTF_InsertTextString(TTF_Text *text, int offset, const char *string, size_t length);

引数

TTF_Text *text変更するテキスト
intoffset>= 0のとき先頭から, < 0のとき文字列の末尾からの文字列のバイト単位のオフセット位置. これはUTF-8の検証を行わない. そのためUTF-8シーケンスの境界からのみ削除する必要がある
const char *string挿入するUTF-8テキスト
intlength挿入するバイト数. 0のときNUL終端のテキスト

戻り値

(bool) 成功のとき真, 失敗のとき偽を戻す. SDL_GetError()を呼んで詳細を知ることができる.

詳細

この関数は内部のテキストの再構築を引き起こす場合がある.

スレッドセーフ

この関数はテキストを生成したスレッドから呼ぶ必要がある.

バージョン

SDL_ttf 3.0.0
