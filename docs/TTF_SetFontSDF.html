TTF_SetFontSDF

フォントのSDF(Signed Distance Field)レンダリングの有効無効を設定する

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

bool TTF_SetFontSDF(TTF_Font *font, bool enabled);

引数

const TTF_Font *font問い合わせるフォント
boolenabledSDFを有効にするとき真, 無効にするとき偽

戻り値

(bool) 成功のとき真, 失敗のとき偽を戻す. SDL_GetError()を呼んで詳細を知ることができる.

SDFはフォントを拡大や回転を行っても鮮明に表示されるための手法で, 表示には特別なシェーダーの対応が必要となる.

これはブレンドAPIで利用可能で, 結果のテクスチャのαチャネルに符号ありの距離の値が設定される.

このフォントを使用するTTF_Textオブジェクトは更新され, キャッシュに既に生成されたグリフが存在すれば消去される.

スレッドセーフ

この関数はどのスレッドからも安全に呼べる.

バージョン

SDL_ttf 3.0.0
