SDL_image 3.0 API (アルファベット順)

概要

様々な形式の画像をSDLサーフェイスに読み込むシンプルなライブラリ.

型

  1. IMG_AnimationDecoder - アニメーションデコーダを表すオブジェクトの型
  2. IMG_AnimationEncoder - アニメーションエンコーダを表すオブジェクトの型

構造体

  1. IMG_Animation - アニメーション画像の構造体

列挙体

  1. IMG_AnimationDecoderStatus - アニメーションデコーダの状態を表す列挙体

マクロ

  1. SDL_IMAGE_MAJOR_VERSION - 表示可能な形式: "%d.%d.%d", MAJOR, MINOR, MICRO
  2. SDL_IMAGE_VERSION - 現在のSDL_imageバージョンのバージョン番号のマクロ
  3. SDL_IMAGE_VERSION_ATLEAST - コンパイルされたSDL_imageが少なくともX.Y.Zのとき真と評価されるマクロ
