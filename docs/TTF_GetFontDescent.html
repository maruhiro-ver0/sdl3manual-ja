TTF_GetFontDescent

フォントのベースラインから下端までの距離を得る

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

int TTF_GetFontDescent(const TTF_Font *font);

引数

const TTF_Font *font問い合わせるフォント

戻り値

(int) フォントのディセントを戻す.

詳細

これは負の値で, ベースラインからの相対値である.
