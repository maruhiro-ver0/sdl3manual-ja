TTF_RenderGlyph_Shaded

1文字のUNICODEコードポイントを高画質で新しい8ビットサーフェイスにレンダリングする

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

SDL_Surface * TTF_RenderGlyph_Shaded(TTF_Font *font, Uint32 ch, SDL_Color fg, SDL_Color bg);

引数

TTF_Font *fontレンダリングするフォント
Uint32chレンダリングするコードポイント
SDL_Colorfgテキストの前景色
SDL_Colorbgテキストの背景色

戻り値

(SDL_Surface *) 8ビットパレットサーフェイスを戻す. エラーのときNULLを戻す.

詳細

この関数は新たに8ビットパレットサーフェイスを生成する. サーフェイスの0ピクセルは背景色で, 他のピクセルは段階的な度合いの前景色を表している. この関数は新しいサーフェイスを戻すか, 失敗の場合はNULLを戻す.

グリフはX軸方向にはパッディングやセンタリングを行わず, Y軸方向には通常の位置合わせを行う.

他の画質レベルでのレンダリングはTTF_RenderGlyph_Solid, TTF_RenderGlyph_Blended, TTF_RenderGlyph_LCDで行える.

スレッドセーフ

この関数はフォントを生成したスレッドから呼ぶ必要がある.

バージョン

SDL_ttf 3.0.0
