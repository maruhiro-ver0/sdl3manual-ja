TTF_GetTextSize

テキストオブジェクトのサイズを得る

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

bool TTF_GetTextSize(TTF_Text *text, int *w, int *h);

引数

TTF_Text *font問い合わせるTTF_Text
int *w幅のピクセル数の代入先へのポインタ
int *h高さのピクセル数の代入先へのポインタ

戻り値

(bool) 成功のとき真, 失敗のとき偽を戻す. SDL_GetError()を呼んで詳細を知ることができる.

詳細

テキストのサイズはフォントやフォントスタイルとサイズを変更すると変わる場合がある.

スレッドセーフ

この関数はテキストを生成したスレッドから呼ぶ必要がある.

バージョン

SDL_ttf 3.0.0
