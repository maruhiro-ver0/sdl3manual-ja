TTF_GetFontStyle

フォントのスタイルを得る

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

TTF_FontStyleFlags TTF_GetFontStyle(const TTF_Font *font);

引数

const TTF_Font *font問い合わせるフォント

戻り値

(TTF_FontStyleFlags) 現在のフォントのスタイルをビットの論理和で戻す.

詳細

フォントのスタイルは次のビットフラグの論理和である:

  • TTF_STYLE_NORMAL (0)
  • TTF_STYLE_BOLD
  • TTF_STYLE_ITALIC
  • TTF_STYLE_UNDERLINE
  • TTF_STYLE_STRIKETHROUGH

スレッドセーフ

この関数はどのスレッドからも安全に呼べる.
