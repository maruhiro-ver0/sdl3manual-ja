TTF_GetPreviousTextSubString

テキストオブジェクト内の前の部分文字列を得る

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

bool TTF_GetPreviousTextSubString(TTF_Text *text, const TTF_SubString *substring, TTF_SubString *previous);

引数

TTF_Text *text問い合わせるTTF_Text
const TTF_SubString *substring問い合わせるTTF_SubString
TTF_SubString *next前の部分文字列の代入先へのポインタ

戻り値

(bool) 成功のとき真, 失敗のとき偽を戻す. SDL_GetError()を呼んで詳細を知ることができる.

詳細

テキストの先頭で呼んだ場合, この関数はTTF_SUBSTRING_TEXT_STARTフラグを付けてテキストの先頭から始まる長さ0の部分文字列を戻す.

スレッドセーフ

この関数はテキストを生成したスレッドから呼ぶ必要がある.

バージョン

SDL_ttf 3.0.0
