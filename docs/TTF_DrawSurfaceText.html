TTF_DrawSurfaceText

SDLサーフェイスにテキストを描く

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

bool TTF_DrawSurfaceText(TTF_Text *text, int x, int y, SDL_Surface *surface);

引数

TTF_Text *text描画するテキスト
intxピクセル単位のX座標. 左から右が正の方向
intyピクセル単位のY座標. 上から下が正の方向
SDL_Surface *surface描画するサーフェイス

戻り値

(bool) 成功のとき真, 失敗のとき偽を戻す. SDL_GetError()を呼んで詳細を知ることができる.

詳細

textはTTF_CreateSurfaceTextEngine()が生成したTTF_TextEngineで生成されたものである必要がある.

スレッドセーフ

この関数はテキストを生成したスレッドから呼ぶ必要がある.

バージョン

SDL_ttf 3.0.0
