NET_CompareAddresses

2つのNET_Addressを比較する

ヘッダ

SDL3_net/SDL_net.h

構文

int NET_CompareAddresses(const NET_Address *a, const NET_Address *b);

引数

const NET_Address *a比較する1番目のアドレス
const NET_Address *b比較する2番目のアドレス

戻り値

(int) aがb未満のとき0未満の数, aがbより大きいとき0より大きい数, 等しいとき0を戻す.

詳細

この関数は2つのアドレスを比較し, qsort(またはSDL_qsort)で使用できる値を戻す.

スレッドセーフ

この関数はどのスレッドからも安全に呼べる.

バージョン

SDL_net 3.0.0以降
