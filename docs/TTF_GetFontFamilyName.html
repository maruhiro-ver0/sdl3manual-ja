TTF_GetFontFamilyName

フォントのファミリー名を得る

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

const char * TTF_GetFontFamilyName(const TTF_Font *font);

引数

const TTF_Font *font問い合わせるフォント

戻り値

(const char *) フォントのファミリー名を戻す.

詳細

この文字列はフォントファイル内の記述による.

戻された文字列は内部に格納されており, 呼び出し側は修正や解放を行おうとしてはならない. フォントをTTF_CloseFont()で破棄すると, この文字列はフォントの他の部分と同様に無効となる.

スレッドセーフ

この関数はどのスレッドからも安全に呼べる.

バージョン

SDL_ttf 3.0.0
