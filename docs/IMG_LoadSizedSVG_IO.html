IMG_LoadSizedSVG_IO

SVG画像指定のサイズに拡大縮小して読み込む

ヘッダ

SDL3_image/SDL_image.h

構文

SDL_Surface * IMG_LoadSizedSVG_IO(SDL_IOStream *src, int width, int height);

引数

SDL_IOStream *src読み込むSDL_IOStream
intwidth生成されるSDL_Surfaceの幅(ピクセル数)
intheight生成されるSDL_Surfaceの高さ(ピクセル数)

戻り値

(SDL_Surface *) 成功したときSDL_Surfaceを戻す. エラーのときNULLを戻す

詳細

SVGファイルは解像度非依存のため, この関数では出力画像のサイズを指定して生成することができる.

widthとheightのどちらかを0にすると, 縦横比を保つようにサイズが自動的に設定される.

戻されたSDL_Surfaceは, アプリケーションがSDL_DestroySurface()を呼んで破棄する必要がある.

バージョン

SDL_image 3.0.0以降
