TTF_GetFontAscent

フォントのベースラインから上端までの距離を得る

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

int TTF_GetFontAscent(const TTF_Font *font);

引数

TTF_Font *font問い合わせるフォント

戻り値

(int) フォントのアセントを戻す.

詳細

これは正の値で, ベースラインからの相対値である.
