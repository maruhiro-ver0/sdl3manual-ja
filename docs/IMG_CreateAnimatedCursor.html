IMG_CreateAnimatedCursor

アニメーションからアニメーションカーソルを生成する

ヘッダ

SDL3_image/SDL_image.h

構文

SDL_Cursor * IMG_CreateAnimatedCursor(IMG_Animation *anim, int hot_x, int hot_y);

引数

IMG_Animation *animアニメーションカーソルの生成で使用されるアニメーション
inthot_xカーソルホットスポットのX座標
inthot_yカーソルホットスポットのY座標

戻り値

(SDL_Cursor *) 成功のとき生成されたカーソルを戻す. 失敗のときNULLを戻す. SDL_GetError()を呼んで詳細を知ることができる.

バージョン

SDL_image 3.4.0以降
