TTF_CreateText

UTF-8テキストとテキストエンジンからテキストオブジェクトを生成する

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

TTF_Text * TTF_CreateText(TTF_TextEngine *engine, TTF_Font *font, const char *text, size_t length);

引数

TTF_TextEngine *engineテキストオブジェクトの生成で使用するテキストエンジン. NULLも可
TTF_Font *fontレンダリングで使用するフォント
const char *text使用するUTF-8テキスト
size_tlengthテキストのバイト数. 0のときNUL終端テキスト

戻り値

(TTF_Text *) TTF_Textを戻す. 失敗のときNULLを戻す. SDL_GetError()を呼んで詳細を知ることができる.

スレッドセーフ

この関数はフォントとテキストエンジンを生成したスレッドから呼ぶ必要がある.

バージョン

SDL_ttf 3.0.0
