TTF_GetGlyphMetrics

フォントの指定のUNICODEコードポイントのグリフのメトリクスを得る

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

bool TTF_GetGlyphMetrics(TTF_Font *font, Uint32 ch, int *minx, int *maxx, int *miny, int *maxy, int *advance);

引数

TTF_Font *font問い合わせるフォント
Uint32chチェックするコードポイント
int *minx境界ボックスの左端を原点としたグリフの最小X座標. この値は負もありうる
int *maxx境界ボックスの左端を原点としたグリフの最大X座標
int *miny境界ボックスの下端を原点としたグリフの最小Y座標. この値は負もありうる
int *maxy境界ボックスの下端を原点としたグリフの最大Y座標
int *advance境界ボックスの下端を原点とした次のグリフまでの距離

戻り値

(bool) 成功のとき真, 失敗のとき偽を戻す. SDL_GetError()を呼んで詳細を知ることができる.

詳細

メトリクスの意味を理解するには次のリンクが役立つ:

https://freetype.sourceforge.net/freetype2/docs/tutorial/step2.html

スレッドセーフ

この関数はフォントを生成したスレッドから呼ぶ必要がある.

バージョン
