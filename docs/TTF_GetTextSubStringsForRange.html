TTF_GetTextSubStringsForRange

テキスト内の指定の範囲の部分文字列を得る

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

TTF_SubString ** TTF_GetTextSubStringsForRange(TTF_Text *text, int offset, int length, int *count);

引数

TTF_Text *text問い合わせるTTF_Text
intoffsetテキスト文字列のオフセットバイト
intlengthテキスト文字列の長さのバイト数. -1のとき残りの全ての文字列
int *count戻された部分文字列の数の代入先へのポインタ. NULLも可

戻り値

(TTF_SubString **) NULL終端の部分文字列の配列を戻す. 失敗のときNULLを戻す. SDL_GetError()を呼んで詳細を知ることができる. これは単一の領域が確保されており, 不要になったときSDL_free()で解放する必要がある.

スレッドセーフ

この関数はテキストを生成したスレッドから呼ぶ必要がある.

バージョン

SDL_ttf 3.0.0
