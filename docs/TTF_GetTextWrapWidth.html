TTF_GetTextWrapWidth

テキストオブジェクトの改行が有効か否かを得る

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

bool TTF_GetTextWrapWidth(TTF_Text *text, int *wrap_width);

引数

TTF_Text *text問い合わせるTTF_Text
int *wrap_width最大幅のピクセル数の代入先へのポインタ. テキストが改行文字のみで改行する場合は0が代入される

戻り値

(bool) 成功のとき真, 失敗のとき偽を戻す. SDL_GetError()を呼んで詳細を知ることができる.

スレッドセーフ

この関数はテキストを生成したスレッドから呼ぶ必要がある.

バージョン

SDL_ttf 3.0.0
