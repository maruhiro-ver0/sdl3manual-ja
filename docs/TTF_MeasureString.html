TTF_MeasureString

指定した幅にUTF-8文字列がどれだけ収まるかを求める

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

bool TTF_MeasureString(TTF_Font *font, const char *text, size_t length, int max_width, int *measured_width, size_t *measured_length);

引数

TTF_Font *font問い合わせるフォント
const char *textUTF-8でエンコードされたテキスト
size_tlengthテキストのバイト数. 0のときNUL終端のテキスト
intmax_width文字列の最大幅ピクセル数. 0のとき制限しない
int *measured_width最大幅に収まる文字列の幅ピクセル数. NULLも可
size_t *measured_length最大幅に収まる文字列のバイト数. NULLも可

戻り値

(bool) 成功のとき真, 失敗のとき偽を戻す. SDL_GetError()を呼んで詳細を知ることができる.

詳細

この関数はmax_widthに達するまでにレンダリングできる文字数を報告する.

この計算のために文字列をレンダリングする必要はない.

スレッドセーフ

この関数はフォントを生成したスレッドから呼ぶ必要がある.

バージョン

SDL_ttf 3.0.0
