MIX_Version

動的リンクされたSDL_mixerライブラリのバージョンを得る

ヘッダ

SDL3_mixer/SDL_mixer.h

構文

int MIX_Version(void);

戻り値

(int) リンクされたバージョンを戻す.

詳細

SDL_mixerを動的にリンクする場合, 現在のバージョンとコンパイル時のバージョンが異なることがありうる. この関数は現在のバージョンを戻し, SDL_MIXER_VERSIONはコンパイル時のバージョンを戻す.

この関数はMIX_Init()を呼ぶ前を含むいつでも呼ぶことができる.

バージョン

SDL_image 3.0.0以降
