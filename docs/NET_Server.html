NET_Server

ストリーム接続の受信側の型

ヘッダ

SDL3_net/SDL_net.h

構文

typedef struct NET_Server NET_Server;

詳細

これはアプリケーションがハンドルとして扱う不透明なデータ型である.

内部的には, これはBSDソケットでは「listenソケット」と呼ばれるものである. クライアントはサーバへのアクセスを試み, サーバが接続をacceptすると, その接続を通して送信と受信を行えるストリームソケットをアプリケーションに提供する.

バージョン

SDL_net 3.0.0以降
