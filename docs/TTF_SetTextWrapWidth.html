TTF_SetTextWrapWidth

テキストオブジェクトの改行の有効無効を設定する

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

bool TTF_SetTextWrapWidth(TTF_Text *text, int wrap_width);

引数

TTF_Text *text設定するTTF_Text
intwrap_width最大幅のピクセル数. 0のときテキストは改行文字のみで改行する

戻り値

(bool) 成功のとき真, 失敗のとき偽を戻す. SDL_GetError()を呼んで詳細を知ることができる.

詳細

この関数は内部のテキスト表現を再構成する場合がある.

スレッドセーフ

この関数はテキストを生成したスレッドから呼ぶ必要がある.

バージョン

SDL_ttf 3.0.0
