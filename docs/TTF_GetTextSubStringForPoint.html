TTF_GetTextSubStringForPoint

テキスト内の指定の位置に最も近い位置の部分文字列を戻す

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

bool TTF_GetTextSubStringForPoint(TTF_Text *text, int x, int y, TTF_SubString *substring);

引数

TTF_Text *text問い合わせるTTF_Text
intxテキストの左からのX座標. テキスト領域の外でもよい
intyテキスト領域の上からのY座標. テキスト領域の外でもよい
TTF_SubString *substring指定の位置に最も近い部分文字列の代入先へのポインタ

戻り値

(bool) 成功のとき真, 失敗のとき偽を戻す. SDL_GetError()を呼んで詳細を知ることができる.

詳細

この関数はテキスト内の指定の位置に最も近い部分文字列を戻す.

スレッドセーフ

この関数はテキストを生成したスレッドから呼ぶ必要がある.

バージョン

SDL_ttf 3.0.0
