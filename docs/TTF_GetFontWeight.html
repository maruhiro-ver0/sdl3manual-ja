TTF_GetFontWeight

フォントの重み(文字の太さ)を得る

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

int TTF_GetFontWeight(const TTF_Font *font);

引数

TTF_Font *font問い合わせるフォント

値

TTF_FONT_WEIGHT_THIN100Thin (100)
TTF_FONT_WEIGHT_EXTRA_LIGHT200ExtraLight (200)
TTF_FONT_WEIGHT_LIGHT300Light (300)
TTF_FONT_WEIGHT_NORMAL400Normal (400)
TTF_FONT_WEIGHT_MEDIUM500Medium (500)
TTF_FONT_WEIGHT_SEMI_BOLD600SemiBold (600)
TTF_FONT_WEIGHT_BOLD700Bold (700)
TTF_FONT_WEIGHT_EXTRA_BOLD800ExtraBold
TTF_FONT_WEIGHT_BLACK900Black (900)
TTF_FONT_WEIGHT_EXTRA_BLACK950ExtraBlack (950)

戻り値

(int) 現在のフォントを重みを戻す.

スレッドセーフ

この関数はフォントを生成したスレッドから呼ぶ必要がある.

バージョン

SDL_ttf 3.2.2
