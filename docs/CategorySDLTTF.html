SDL_ttf 3.0 API (アルファベット順)

概要

このライブラリは優れたFreeType 2.0ライブラリのラッパーである.

型

  1. TTF_Font - フォント情報を持つ内部構造の型
  2. TTF_FontStyleFlags - TTF_Fontのフォントスタイルフラグの型
  3. TTF_SubStringFlags - TTF_SubStringのフラグの型
  4. TTF_TextData - TTF_Textの内部データ型
  5. TTF_TextEngine - テキストオブジェクトの生成で使用するテキストエンジンの型

構造体

  1. TTF_GLAtlasDrawSequence - TTF_GetGLTextDrawDataが戻した描画シーケンスの連結リストの構造体
  2. TTF_GLAtlasDrawVertex - TTF_GetGLTextDrawDataが戻した描画データの頂点
  3. TTF_GPUAtlasDrawSequence - TTF_GetGPUTextDrawDataが戻した描画シーケンスの連結リストの構造体
  4. TTF_SubString - テキスト内の部分文字列を表す構造体
  5. TTF_Text - TTF_CreateText()で生成されたテキストの構造体

列挙体

  1. TTF_CopyOperationFlags - TTF_GPUAtlasDrawSequenceが戻すフラグの列挙体
  2. TTF_Direction - 方向フラグの列挙体
  3. TTF_GLTextEngineWinding - TTF_GetGLTextDrawDataが戻した頂点の巻き順の列挙体
  4. TTF_GPUTextEngineWinding - TTF_GetGPUTextDrawDataが戻した頂点の巻き順の列挙体
  5. TTF_HintingFlags - TTF(TrueTypeフォント)のヒンティングフラグの列挙体
  6. TTF_HorizontalAlignment - 改行するテキストをレンダリングする場合の水平方向の配置の列挙体
  7. TTF_ImageType - グリフ画像のデータの形式の列挙体

マクロ

  1. SDL_TTF_MAJOR_VERSION - SDL_ttfヘッダのメジャーバージョンのマクロ
  2. SDL_TTF_VERSION - SDL_ttfヘッダのバージョンマクロ
  3. SDL_TTF_VERSION_ATLEAST - 少なくともX.Y.ZのバージョンのSDL_ttfでコンパイルされたとき真と評価するマクロ
  4. TTF_HINTING_NORMAL - ヒンティングのフラグ
  5. TTF_STYLE_NORMAL - フォントスタイルのフラグ
