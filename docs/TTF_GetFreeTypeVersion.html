TTF_GetFreeTypeVersion

使用しているFreeTypeライブラリのバージョンを得る

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

void TTF_GetFreeTypeVersion(int *major, int *minor, int *patch);

引数

int *majorメジャーバージョンの代入先へのポインタ. NULLも可
int *minorマイナーバージョンの代入先へのポインタ. NULLも可
int *patchパッチバージョンの代入先へのポインタ. NULLも可

スレッドセーフ

この関数を呼ぶ前にTTF_Init()を呼んでいる必要がある.
