MIX_SetTagGain

特定のタグのトラックのゲインを設定する

ヘッダ

SDL3_mixer/SDL_mixer.h

構文

bool MIX_SetTagGain(MIX_Mixer *mixer, const char *tag, float gain);

引数

MIX_Group *mixerタグを検索するミキサー
const char *tagトラックの検索で使用するタグ
floatgain新しいゲインの値

戻り値

(bool) 成功のとき真, 失敗のとき偽を戻す. SDL_GetError()を呼んで詳細を知ることができる.

詳細

それぞれのトラックにはそれぞれのゲインがあり, トラック全体のボリュームを調整する. このトラックからのサンプルは, このゲインの値で修正される. ゲインは0は無音で, 1.0fはミックスしたボリュームを変更しない. そして, 1.0fを超える場合はボリュームを増す. 負の数は不正な値である. ゲインの上限はないが, 音が非常に大きくなりうるので, 設定には注意すること.

トラックのゲインのデフォルトは1.0fである.

この値は後のミックスのためにいつでも変更できる.

ミキシング処理の視点では, 成功した全てのトラックは完全に同時にゲインの値が変更される.

この値は後のミックスのためにいつでも変更できる.

この関数はどのスレッドからも安全に呼べる.
