TTF_FontIsFixedWidth

フォントが等幅かチェックする

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

bool TTF_FontIsFixedWidth(const TTF_Font *font);

引数

const TTF_Font *fontチェックするフォント

戻り値

(bool) フォントが等幅ならば真, そうでなければ偽を戻す.

詳細

「等幅」は全てのグリフの幅が全て同じフォントであることを表している. 例えば, 小文字の'i'と大文字の'W'の幅は同じになる. これはターミナルやテキストエディタやテキストをグリッドとして扱うアプリケーションでは一般的である. 他の多くの場合(WYSIWYGワープロ, webページなど)は, ほとんどが等幅ではない.

スレッドセーフ

この関数はどのスレッドからも安全に呼べる.

バージョン
