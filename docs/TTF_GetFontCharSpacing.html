TTF_GetFontCharSpacing

レンダリングされた2つの文字の間に挿入される空白をピクセル単位で得る

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

int TTF_GetFontCharSpacing(const TTF_Font *font);

引数

const TTF_Font *font問い合わせるフォント

戻り値

(int) ピクセル単位の文字間スペースを戻す.

詳細

設定されていないデフォルトの値は0である.

スレッドセーフ

この関数はフォントを生成したスレッドから呼ぶ必要がある.

バージョン

SDL_ttf 3.4.0
