TTF_GetHarfBuzzVersion

使用しているHarfBuzzライブラリのバージョンを得る

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

void TTF_GetHarfBuzzVersion(int *major, int *minor, int *patch);

引数

int *majorメジャーバージョンの代入先へのポインタ. NULLも可
int *minorマイナーバージョンの代入先へのポインタ. NULLも可
int *patchパッチバージョンの代入先へのポインタ. NULLも可

詳細

HarfBuzzを使用できない場合, バージョンは0.0.0となる.

スレッドセーフ

この関数はどのスレッドからも安全に呼べる.

バージョン
