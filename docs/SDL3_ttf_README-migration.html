SDL_ttf 3.0への移行

概要

ここではアプリケーションをSDL_ttf 2.0からSDL_ttf 3.0に移行するために役立つ情報を提供する.

関数は以前は負の数のエラーコードを戻していたが, ブール値を戻すようになった.

このようなコードは... 

    if (TTF_Function() < 0 || TTF_Function() == -1) {
        /* 失敗... */
    }

または 

    if (TTF_Function() == 0) {
        /* 成功... */
    }

または 

    if (!TTF_Function()) {
        /* 成功... */
    }

このように変更しなければならない 

    if (TTF_Function()) {
        /* 成功... */
    } else {
        /* 失敗... */
    }

いくつかの関数は名称が変更された. SDL3への移行をより簡単にするセマンティックパッチが用意されている: SDL_migration.cocci

APIではUTF-8を使用するようになった. 以前はLatin-1, UTF-8, UCS2の3つの関数があったが, 現在はUTF-8のみを受け入れるようになった. さらに, これらの関数には長さの引数が追加され, 文字列の一部をレンダリングできるようになった.

背景色のαが0ならば透明になるようになった.
