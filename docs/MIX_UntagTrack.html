MIX_UntagTrack

トラックの任意のタグを取り除く

ヘッダ

SDL3_mixer/SDL_mixer.h

構文

void MIX_UntagTrack(MIX_Track *track, const char *tag);

引数

MIX_Track *trackタグを取り除くトラック
const char *tag取り除くタグ

詳細

タグにはUTF-8でコード化したあらゆる有効なC文字列を設定できる. これは様々な目的でトラックをグループ化する場合に有用である. 例えばゲーム中で使用する全てのトラックに"game"をマークすると, ユーザが設定メニューを開いたとき, アプリケーションは即座にゲームプレーに関係する全てのトラックを一時停止させるがBGMと効果音は継続するようなことができる.

トラックに関連付けられていないタグを取り除こうとしても問題ない. この関数はエラーを報告しないが, 単に何も起こらない.

タグとしてNULLを指定すると, 全てのタグが取り除かれる.

スレッドセーフ

この関数はどのスレッドからも安全に呼べる.
