TTF_RenderText_Solid_Wrapped

改行するUTF-8テキストを速度重視の画質で新しい8ビットサーフェイスにレンダリングする

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

SDL_Surface * TTF_RenderText_Solid_Wrapped(TTF_Font *font, const char *text, size_t length, SDL_Color fg, int wrapLength);

引数

TTF_Font *fontレンダリングするフォント
const char *textレンダリングするUTF-8テキスト
size_tlengthテキストのバイト長. 0のときNUL終端のテキスト
SDL_Colorfgテキストの前景色
intwrap_widthtextサーフェイスの最大幅. 0のとき改行文字のみで改行する

戻り値

(SDL_Surface *) 8ビットパレットサーフェイスを戻す. エラーのときNULLを戻す.

詳細

この関数は新たに8ビットパレットサーフェイスを生成する. サーフェイスの0ピクセルはキーカラーで, 透明な背景色となる. 1ピクセルは設定されたテキストの色である.

テキストはピクセル数がwrap_widthを超えるとき行末または単語の区切りで改行される.

wrap_widthが0のとき, 改行コードの場合のみ改行する.

他の画質レベルでのレンダリングはTTF_RenderText_Shaded_Wrapped, TTF_RenderText_Blended_Wrapped, TTF_RenderText_LCD_Wrappedで行える.

スレッドセーフ

この関数はフォントを生成したスレッドから呼ぶ必要がある.
