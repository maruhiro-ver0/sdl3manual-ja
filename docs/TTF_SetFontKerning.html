TTF_SetFontKerning

フォントのカーニングの状態を得る

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

void TTF_SetFontKerning(TTF_Font *font, bool enabled);

引数

const TTF_Font *font設定するフォント
boolenabled真のときカーニングを有効にする. 偽のとき無効にする

詳細

新たに開いたとき, フォントのカーニングは有効になっている. レンダリングの結果は良くなる場合が多いため, 特別な理由がない限り無効にしないのはよい方針である. (例えば一部のフォントはカーニングを無効にするとkerningがkemingのようになってしまう.)

このフォントを使用するTTF_Textオブジェクトは更新される.

スレッドセーフ

この関数はどのスレッドからも安全に呼べる.

バージョン

SDL_ttf 3.0.0
