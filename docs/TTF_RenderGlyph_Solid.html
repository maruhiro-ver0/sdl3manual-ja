TTF_RenderGlyph_Solid

1文字のUNICODEコードポイントを速度重視の品質で新しい8ビットサーフェイスにレンダリングする

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

SDL_Surface * TTF_RenderGlyph_Solid(TTF_Font *font, Uint32 ch, SDL_Color fg);

引数

TTF_Font *fontレンダリングするフォント
Uint32chレンダリングするコードポイント
SDL_Colorfgテキストの前景色

戻り値

(SDL_Surface *) 82ビットパレットサーフェイスを戻す. エラーのときNULLを戻す.

詳細

この関数は8ビットパレットサーフェイスを確保する. サーフェイスの0ピクセルはカラーキーで背景は透明になる. 1は指定したテキストの色である.

グリフはX軸方向にはパッディングやセンタリングを行わず, Y軸方向には通常の位置合わせを行う.

他の品質レベルでのレンダリングはTTF_RenderGlyph_Shaded, TTF_RenderGlyph_Blended, TTF_RenderGlyph_LCDで行える.

スレッドセーフ

この関数はフォントを生成したスレッドから呼ぶ必要がある.

バージョン

SDL_ttf 3.0.0
