MIX_DecodeAudio

MIX_AudioDecoderからオーディオデータを追加でデコードする

ヘッダ

SDL3_mixer/SDL_mixer.h

構文

int MIX_DecodeAudio(MIX_AudioDecoder *audiodecoder, void *buffer, int buflen, const SDL_AudioSpec *spec);

引数

MIX_AudioDecoder *audiodecoder追加のデータを得るデコーダ
void *bufferデコードされたオーディオデータを格納するメモリバッファ
intbuflenバッファに格納する最大バイト数
const SDL_AudioSpec *specバッファに格納するオーディオデータの形式

戻り値

(int) デコードされたバイト数を戻す. エラーのとき-1を戻す. SDL_GetError()を呼んで詳細を知ることができる.

詳細

どのような形式でもデータは必要なときデコードされる. 形式は呼び出しの間で変更できる.

この関数はデコードしたバイト数を戻すため, エラーまたはファイルの終端に達した場合は要求より少ない場合がある. 戻り値が0の場合はファイル全体をデコードしたことを表し, -1の場合は回復不能なエラーが発生したことを表す.

スレッドセーフ

この関数はどのスレッドからも安全に呼べる.

バージョン

SDL_image 3.0.0以降
