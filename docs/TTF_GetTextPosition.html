TTF_GetTextPosition

テキストオブジェクトの位置を得る

ヘッダ

SDL3_ttf/SDL_ttf.h

構文

bool TTF_GetTextPosition(TTF_Text *text, int *x, int *y);

引数

TTF_Text *text問い合わせるTTF_Text
int *xテキストの左上からのX軸方向のオフセットの代入先へのポインタ. NULLも可
int *yテキストの左上からのY軸方向のオフセットの代入先へのポインタ. NULLも可

戻り値

(bool) 成功のとき真, 失敗のとき偽を戻す. SDL_GetError()を呼んで詳細を知ることができる.

スレッドセーフ

この関数はテキストを生成したスレッドから呼ぶ必要がある.

バージョン

SDL_ttf 3.0.0
